# noting my absence

I thought it was appropriate to note my absence from this blog and let you know what is coming soon.
I have been working diligently on [chess, again](2026-07-09-chess.md), and I intend to document
the implementation details here.

I also want to write about math, especially about the classes that I have taken in school. My
current classes are not as interesting to write about (maybe I'll post later about Introduction
to Topology, but who knows).

I actually have a backlog of things to post, believe it or not, although some don't really read
like blog posts. I still want to post them. As those who know me know, I've always wanted to teach, so
when I'm studying something really hard I find it best for me to write about it as if I'm teaching
it to somebody. Although I always try to simplify things so that anyone can understand, I know that
ultimately that's not the case. As I write and edit these documents, I get more and more familiar with
their content, and my expectations for what intuitively makes sense to anybody raises with it. So
give me a break.

I don't know if this is just me, but my Instagram is now flooded with all these screenshots of
obviously AI-generated LaTeX documents with content similar to mine, attempting to introduce
advanced math topics to anyone. But rest assured, I've written every single one by hand. And I think
mine are better.
